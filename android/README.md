# ResearchMate AI Android 0.5.0
Multi-select OpenAlex results and batch transfer to Prompt Studio. Save individual papers in a local saved-papers project. Create, reopen, update and delete app-private local projects using SharedPreferences JSON. Reject future years and invalid year ranges. Choose output type: original research, narrative/systematic review, meta-analysis, proposal, thesis chapter, industrial report, critique, poster or research map. Set target score 60–98 and revision loop 1–8 rounds. Prompt includes scientific writing conventions, output-specific structures, evidence integrity, weighted rubric, reviewer pass, revision cycle and honest stop conditions. Includes subtle icons, elevated cards and animated transitions.
Projects are local and not synced; clearing app data or uninstalling may delete them. Original PDFs are not stored yet. The 0–100 score is an internal writing-quality rubric, not journal ranking, acceptance probability, impact factor or Q1–Q4. The Android app does not itself execute an LLM or verify the target score.
