# ResearchMate AI — Version 0.2

نسخه دوم آزمایشی دستیار پژوهشی نیمه‌مستقل، با تمرکز بر کشف ادبیات علمی و تحلیل مقدماتی ارتباط مقالات.

## قابلیت‌ها
- جست‌وجوی مقالات OpenAlex و فیلتر سال/دسترسی آزاد
- خروجی CSV و BibTeX
- بارگذاری چند PDF و استخراج متن
- تخمین شباهت متنی مقاله‌ها با TF-IDF
- شناسایی احتمالی خانواده روش‌ها با واژگان کلیدی
- استخراج نشانه‌های محدودیت و کار آینده از چکیده‌ها
- پیشنهاد شکاف‌های پژوهشی اولیه و قابل بررسی
- ثبت بازخورد پژوهشگر در نشست جاری
- تولید گزارش PDF شامل منابع، روش‌ها، موضوعات، شکاف‌های پیشنهادی و محدودیت‌ها

## محدودیت‌های مهم
- شباهت TF-IDF فقط شباهت واژگانی است، نه اثبات ارتباط علمی یا رابطه علّی.
- شناسایی روش‌ها و شکاف‌ها مبتنی بر قواعد و واژگان است و ممکن است خطا کند.
- یادگیری پایدار بین نشست‌ها و آموزش مدل اختصاصی در این نسخه وجود ندارد.
- PDFها فقط در نشست فعلی نگهداری می‌شوند؛ فضای ذخیره‌سازی ابری Streamlit را برای نگهداری دائمی فرض نکنید.
- خروجی PDF گزارش کمکی است و جایگزین مرور نظام‌مند، بررسی متن کامل یا داوری متخصص نیست.

## اجرا
```bash
pip install -r requirements.txt
streamlit run app.py
```

## استقرار
در مخزن GitHub، فایل‌های پروژه را جایگزین نسخه قبلی کنید. فایل اصلی `app.py` است.
