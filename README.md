# ResearchMate AI 2.0 — deterministic research tools + prompt studio

ResearchMate separates scientific workflows into two independent tracks. The application does not call a language-model API. It combines deterministic scholarly retrieval and extraction with a configurable prompt generator for AI-dependent analysis tasks performed by an external model selected by the user.

## Workflow A — functions that run without an AI model

Open **1_ابزارهای_بدون_AI** from the Streamlit pages menu.

- Exploratory OpenAlex discovery of journal articles/reviews explicitly marked Open Access, within a selected publication-year range.
- Bibliographic metadata and DOI inspection.
- Legal OA full-text retrieval attempts via verified OA locations, Europe PMC, and optional OpenAlex/Unpaywall routes. No paywall or access-control bypass is attempted.
- PDF/XML/HTML text extraction, page-level text where available, and table extraction where supported by the parser.
- Deterministic keyword/pattern-based candidate extraction for method terms, material terms, numeric patterns/units, result-like paragraphs, and limitation-like paragraphs.
- Export of metadata, candidate signals, evidence excerpts, extracted tables, full text, BibTeX, JSON, Excel workbook, and a ZIP package.

**Important boundary:** keyword and pattern matches are not semantic scientific analysis. They can miss relevant statements or return false positives. Extracted PDF tables and figures may be incomplete. This route does not establish mechanisms, research novelty/gaps, causality, study quality, or peer-review decisions. OpenAlex discovery is exploratory and is not an exhaustive systematic search.

## Workflow B — AI-assisted tasks through a prompt generated by ResearchMate

Open **2_سازنده_پرامپت** from the Streamlit pages menu.

The user selects the task, field, academic level, report/article type, output language (Persian or English), sources, citation style, desired functions, and review settings. ResearchMate builds an English prompt that:

1. inventories every accessible source and classifies its evidence-access level;
2. maps sections, subsections, figures, tables, equations, appendices, and identified topics to a coverage matrix;
3. runs the selected technical analyses and requires evidence traceability;
4. distinguishes source facts, reproducible calculations, interpretation, and hypotheses;
5. performs bounded draft → critique → correction → re-check cycles;
6. conducts a separate referee-style quality gate and reports PASS, PASS WITH LIMITATIONS, or NOT APPROVED;
7. includes unresolved access and evidence limitations instead of fabricating information.

The prompt generator itself is deterministic and does not use an LLM API. The generated prompt must be pasted into an AI service selected by the user. To inspect inaccessible links, the user must provide a legally obtained full-text file and use a target model that supports file upload and/or web access. A prompt cannot grant a model technical access to a link.

The reviewer role is an AI-assisted internal quality check, not an independent human peer review or a guarantee of correctness or journal acceptance. Hidden chain-of-thought is not requested; the output should show concise evidence-based decisions and a revision log.

## Application entry point

The root page is a navigation-only landing page for the two workflows. The former integrated Gemini/API workflow is not exposed in the primary user interface.

## Run locally

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## Data and privacy notes

- The AI-free research page sends search requests to OpenAlex and may contact repositories/Europe PMC/Unpaywall to obtain openly available records or files.
- Optional OpenAlex API key and Unpaywall email are entered at runtime; do not commit credentials or store them in public files.
- The Prompt Studio does not transmit sources to any AI provider. The user decides which external AI service receives the generated prompt and any attached articles.
- Streamlit Community Cloud session storage is temporary; this version does not implement user accounts or persistent private project storage.
