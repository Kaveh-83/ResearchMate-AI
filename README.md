# ResearchMate AI — MVP 0.1

وب‌اپ اولیه و کم‌هزینه برای کشف مقالات علمی و مدیریت مقدماتی مرور ادبیات.

## امکانات فعلی
- جست‌وجوی مقاله از API عمومی OpenAlex
- فیلتر بازه زمانی و دسترسی آزاد
- نمایش عنوان، سال، نویسندگان، منبع، استناد، DOI و چکیده در صورت وجود
- خروجی CSV و BibTeX
- انتخاب و مقایسه فراداده‌ای چند مقاله
- بارگذاری PDF و استخراج متن (آزمایشی)

## محدودیت‌های علمی مهم
- این نسخه هنوز ایجنت هوش مصنوعی کامل نیست.
- تحلیل PDF فعلاً استخراج متن و تشخیص ساده سرفصل‌هاست؛ خلاصه‌سازی استدلالی، ارزیابی کیفیت روش‌شناسی و تشخیص شکاف پژوهشی به مرحله بعد موکول شده است.
- نبود DOI یا چکیده در OpenAlex به معنی نامعتبر بودن مقاله نیست.
- تعداد استناد معیار قطعی کیفیت نیست.
- برای مقاله‌های مهم، DOI و متن ناشر/نسخه مخزن را مستقل بررسی کنید.

## اجرای محلی
نیازمند Python 3.10 یا جدیدتر:

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
streamlit run app.py
```

## استقرار رایگان با Streamlit Community Cloud
1. یک حساب GitHub بسازید یا وارد شوید.
2. یک مخزن جدید با نام `researchmate-ai` ایجاد کنید.
3. فایل‌های این پروژه را در مخزن بارگذاری کنید.
4. به https://share.streamlit.io بروید و GitHub را متصل کنید.
5. مخزن، شاخه اصلی و فایل `app.py` را انتخاب و Deploy کنید.

سرویس‌ها و سقف‌های رایگان ممکن است تغییر کنند؛ پایداری و دسترس‌پذیری دائمی تضمین‌شده نیست.
